# v2-sales-
# Variety and Values Sales Data Work on Excel with Dashboards

## Project Overview
This project focuses on analyzing sales data using Excel and creating dynamic dashboards to visualize key insights. It aims to help businesses make data-driven decisions by providing a clear and comprehensive view of their sales performance.

## Features
- Imported and cleaned sales data from various sources
- Performed data analysis using Excel functions and formulas
- Created interactive dashboards with charts, graphs, and pivot tables
- Customized dashboards to display key performance indicators (KPIs) and trends
